* ### !BlackJack (개인 프로젝트)
* **설명:** C99를 활용하여 터미널 기반의 1대1 블랙잭 게임, 실제 카지노의 카드 분배 방식과 점수 계산 규칙, 그리고 딜러 AI 로직이 구현

* **주요 기능**
1.   **순차적 카드 분배:** 플레이어와 딜러가 번갈아 가며 카드를 받으며, 딜러의 두 번째 카드는 히든 카드로 처리되어 게임의 몰입감을 높임.
2.   **유연한 점수 계산:** 에이스(Ace) 카드를 보유한 경우, 현재 버스트(21초과) 여부에 따라 자동으로 1점 또는 11점으로 계산.
3.   **딜러 AI 시스템:** 카지노 정식 규칙에 따라 딜러는 17점 미만일 때 의무적으로 Hit하고, 17점 이상이 되면 자동으로 Stand함.
4.   **시간 지연 연출:** `sleep()` 함수를 활용하여 카드가 분배되거나 플레이어가 선택할 때 실제 게임을 하는 듯한 딜레이 효과를 주었음.
* **Tech Stack:** `C99`, `main.c`
